# Опрос «Маршрут студента»

Учебный проект для студента 2 курса. Тема полностью заменена: вместо привычек сна — способы передвижения студентов до места учёбы. Оформление изменено на песочный фон со сливовыми и оранжевыми акцентами.

## Запуск
1. Установите Python 3.10 или новее.
2. Откройте терминал в этой папке.
3. Выполните `pip install -r requirements.txt`.
4. Выполните `streamlit run app.py`.

## Возможности
- анкета с выбором вариантов, шкалами и необязательным комментарием;
- сводные показатели и графики после отправки ответов;
- выгрузка ответов в CSV.

## Хранение ответов
В этой учебной версии ответы хранятся в памяти текущего сеанса Streamlit. После перезапуска приложения они могут исчезнуть; скачивайте CSV для сохранения результатов. Постоянная база данных не подключена.

## Публикация
Для публикации загрузите папку проекта в GitHub и подключите репозиторий к Streamlit Community Cloud, указав `app.py` как главный файл.
